# VideoEditor-Pro

Starter working prototype for a social-media video editor built with Python + PySide6.

## Features
- Add media files to a project library
- Send clips into a timeline
- Export to Instagram and Facebook presets
- Batch export multiple social formats

## Requirements
- Python 3.10+
- FFmpeg installed and available on PATH
- PySide6, moviepy, numpy, Pillow

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## Notes
This is a starter prototype, not a full professional NLE. It is suitable for early demo and iteration.
